Eles são usados principalmente para manter informações entre requisições HTTP, como autenticação de usuário, gerenciamento de sessões e rastreamento do comportamento do usuário. Por outro lado, o sessionStorage é projetado para armazenamento temporário e é acessível apenas durante a mesma sessão (ou seja, enquanto a janela ou aba do navegador estiver aberta). Os dados armazenados no sessionStorage são perdidos quando a janela do navegador é fechada. Por fim, o localStorage é semelhante ao sessionStorage, mas persiste mesmo quando a janela ou aba do navegador é fechada e reaberta. Ele fornece armazenamento de longo prazo para aplicações web. É muito semelhante aos cookies, no entanto, o localStorage possui limites de tamanho bem maiores do que os cookies, tornando-o uma alternativa muito melhor para armazenar grandes volumes de dados. Análise (parsing) do HTML O navegador lê o código HTML e constrói uma estrutura de árvore chamada DOM (Document Object Model). Análise do CSS e aplicação dos estilos Os arquivos CSS são carregados e interpretados, e os estilos são aplicados aos elementos do DOM, criando a chamada árvore de renderização. Cálculo da posição de cada elemento no layout da página O navegador determina onde e como cada elemento deve ser exibido na tela, levando em consideração margens, espaçamentos, tamanhos, etc. Pintura dos pixels na tela e organização em camadas O navegador desenha visualmente os elementos (cores, bordas, texto, imagens) e separa o conteúdo em camadas, se necessário. Composição final das camadas para renderizar o site na tela Todas as camadas são combinadas para exibir o site. Nessa etapa são considerados fatores como z-index, opacity, transform e outros efeitos visuais. Execução do código JavaScript Scripts são executados, podendo modificar o DOM ou os estilos, o que pode levar a novas renderizações (reflow/repaint). Carregamento de recursos assíncronos Recursos como imagens, fontes ou dados de APIs são carregados de forma assíncrona, e podem continuar sendo processados mesmo após a página estar visível.
